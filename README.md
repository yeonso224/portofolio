# 🤖 정연소의 AI 피지컬 랩 (AI Physical Lab)

> **50플러스 시니어를 위한 피지컬 컴퓨팅 & 인공지능 로보틱스 포트폴리오 웹사이트**

---

## 📌 프로젝트 개요 (Overview)

**정연소의 AI 피지컬 랩**은 50플러스 센터 특강 현장에서 신중년(50·60·70대) 수강생들에게 인공지능과 로보틱스의 결합인 **'AI 피지컬'**의 개념을 직관적으로 전달하고, 강사의 교육 철학 및 실제 하드웨어/소프트웨어 융합 프로젝트를 효과적으로 소개하기 위해 제작된 반응형 포트폴리오 웹사이트입니다.

- **기획·개발자**: 정연소 (AI 피지컬 & 로보틱스 에듀케이터)
- **목표 사용자**: 50플러스 센터 신중년 수강생 및 특강 담당자
- **핵심 슬로건**: _"모니터 화면 속 글씨에 머물던 AI가 현실에서 로봇과 기계의 손발로 살아 숨 쉽니다."_
- **타깃 환경**: 강의실 대형 빔프로젝터 투사 화면 및 스마트폰/태블릿 모바일 반응형

---

## ✨ 주요 기능 및 특징 (Key Features)

### 1. 시니어 눈높이 맞춤형 접근성 UI (Senior-Friendly Accessibility)

- **3단계 글자 크기 조절**: 헤더 우측의 `가-` / `보통(115%)` / `가+(130%)` 버튼을 통해 시력에 맞춰 실시간 폰트 확대/축소 가능
- **극대화된 가독성**: 본문 기본 18px 이상 폰트 및 16:1 초고대비 딥 차콜(#0F172A) / 퓨어 화이트(#FFFFFF) 색상 대비 설계
- **터치 친화적 컴포넌트**: 손가락 터치와 마우스 클릭이 쉬운 최소 48px 이상의 큼직한 버튼과 카드 인터랙션

### 2. 'AI 피지컬' 3단계 인터랙티브 인포그래픽 (Interactive Diagram)

- **개념 시각화**: 복잡한 인공지능 이론을 사람의 신체 구조에 비유하여 3단계로 직관적 전달
  - **1단계 감각 (Sensing)**: 카메라, 거리, 조도 센서 (사람의 눈과 귀)
  - **2단계 사고 (Thinking)**: 파이썬 AI 알고리즘 두뇌 (판단 및 결정)
  - **3단계 행동 (Action)**: 레고 스파이크 프라임 모터 및 기구부 (움직이는 손과 발)
- 카드를 클릭할 때마다 하단 안내창에 실시간 설명과 일상 속 예시 제공

### 3. 나만 편집 가능한 관리자 모드 (Admin Inline Edit)

- **간편 PIN 인증**: 헤더 우측 또는 소개란의 `🔒 소개 편집` 버튼 클릭 후 4자리 PIN(기본값: `1234`) 입력 시 즉시 편집 모드 활성화
- **화면 위 인라인 편집**: 별도의 관리자 CMS 페이지 없이 브라우저 상에서 자기소개 문구를 바로 수정
- **자동 저장 & 데이터 백업**: 수정된 소개글은 브라우저 `LocalStorage`에 영구 보관되며, 언제든 `📥 백업 파일 받기`를 통해 `profile.json` 형태로 다운로드 가능

### 4. 융합 작업물 갤러리 (Work Showcase)

- **카테고리 필터링**:
  - `전체 보기`
  - `🤖 레고 스파이크 프라임`: 모터·센서 기구학 설계 및 교육용 로봇
  - `🧠 파이썬 AI 융합`: 머신러닝, 비전/음성인식 기반 스마트 기기
  - `⚡ 바이브 코딩`: 생성형 AI 프롬프트 기반 초고속 인터랙티브 웹 프로토타입
- **상세 보기 모달**: 프로젝트 카드를 누르면 작동 원리(감각 ➔ 사고 ➔ 행동), 사용 하드웨어/소프트웨어 스펙, 시니어 교육 관점 해설을 팝업으로 상세 확인 가능

## 🛠️ 기술 스택 (Tech Stack)

| 구분              | 기술 / 도구                             | 설명                                                       |
| :---------------- | :-------------------------------------- | :--------------------------------------------------------- |
| **Frontend**      | HTML5, CSS3, JavaScript (ES6+ Modules)  | 순수 웹 표준 기술을 활용한 빠르고 가벼운 반응형 구조       |
| **Typography**    | Pretendard Web Font                     | 가독성이 우수한 모던 고딕 폰트 적용                        |
| **Design System** | CSS Custom Properties (Variables)       | 일관된 색상/여백/그림자 토큰 기반 디자인 시스템            |
| **Data Storage**  | Web LocalStorage, JSON                  | 서버 DB 없이 브라우저 로컬 저장 및 정적 JSON 데이터 연동   |
| **Local Server**  | PowerShell HTTP Listener (`server.ps1`) | 별도 Node.js/Python 설치 없이 즉시 실행 가능한 내장 웹서버 |

## 🚀 실행 방법 (Getting Started)

### 방법 1. 제공된 PowerShell 스크립트 실행 (권장)

본 프로젝트에 포함된 경량 로컬 서버 스크립트를 실행합니다.

1. 터미널(PowerShell)을 열고 `portfolio` 디렉터리로 이동합니다.
   ```powershell
   cd portfolio
   ```
2. 서버를 구동합니다.
   ```powershell
   .\server.ps1
   ```
3. 웹 브라우저에서 아래 주소로 접속합니다.
   ```
   http://localhost:3000/
   ```

### 방법 2. VS Code Live Server 확장 프로그램 사용

1. VS Code에서 `portfolio/index.html` 파일을 엽니다.
2. 우측 하단의 **"Go Live"** 버튼을 클릭하거나, 마우스 우클릭 후 **"Open with Live Server"**를 선택합니다.

## 🔑 관리자 모드 사용 안내 (Admin Guide)

1. **로그인**: 네비게이션 바 우측 상단의 `🔒 소개 편집` 버튼을 클릭합니다.
2. **비밀번호 입력**: 팝업창에 4자리 PIN 번호인 `1234`를 입력하고 확인을 누릅니다.
3. **내용 수정**: 노란색 관리자 알림 배너가 나타나며, '강사 소개' 텍스트 영역이 편집 가능한 입력창으로 바뀝니다.
4. **저장 및 백업**:
   - `💾 변경사항 저장하기`: 브라우저 LocalStorage에 즉시 반영됩니다.
   - `📥 백업 파일 받기`: 수정된 프로필 데이터를 `profile.json` 파일로 PC에 다운로드합니다.
